# 悬浮翻译 FloatTrans

看电影 / 追剧 / 看直播时随手查词的小工具：**无边框、圆角、永远置顶**，不挡画面，随时收起成一个小圆球。

![预览](icon_preview.png)

## 怎么用

双击 **`启动翻译.bat`**（或打包后的 `FloatTrans.exe`），右上角就会出现一个小面板。

| 操作 | 说明 |
| --- | --- |
| 直接输入 | 在输入框敲单词或句子，按 **回车** 翻译 |
| 复制即译 | 在任意软件里选中文字按 **Ctrl+C**，面板自动翻译（看电影时最好用） |
| 截图取词 | **Ctrl+Alt+S** 或点面板上的 **截图**，屏幕变暗后拖一个框，框里的字自动识别并翻译 |
| 悬停取词 | 点面板上的 **悬停** 打开，之后**按住 Alt** 把鼠标停在任何文字上，旁边弹出小气泡显示译文 |
| 全局热键 | **Ctrl+Alt+T** 随时呼出面板并聚焦输入框；**Ctrl+Alt+H** 开关悬停取词（被占用时自动换备用键） |
| 拖拽 | 按住顶部标题栏拖动；也可以拖那颗小圆球 |
| 收起 | 点标题栏 **─** 变成小圆球；点圆球再展开 |
| 发音 | 点底部 **发音**（默认关闭自动发音，可在设置里开） |
| 复制译文 | 双击译文，或点底部 **复制**；悬停气泡点一下也能复制 |
| 字号 | 按住 **Ctrl** 滚滚轮 |
| 历史 | 输入框里按 **↑ / ↓** 翻看查过的词 |
| 设置 | 点 **⚙**：不透明度、字号、自动翻译、悬停取词、开机自启 |

单词会额外给出**音标 + 词典释义**（有道词典），句子直接给整句翻译。

## 两种取词方式怎么选

| | 截图取词 | 悬停取词 |
| --- | --- | --- |
| 触发 | 按 **Ctrl+Alt+S**，拖框 | 按住 **Alt**，鼠标停住约半秒 |
| 适合 | 视频硬字幕、图片里的字、一整个段落 | 网页、PDF、电子书，边看边查 |
| 结果 | 译文进主面板，可发音 / 复制 / 翻历史 | 鼠标旁弹小气泡，松开 Alt 自动消失 |
| 选区 | 你框多少就认多少 | 自动取鼠标所在的那一行（左右够宽就整行） |

两种方式都走 **Windows 自带 OCR**，完全离线、不联网、几十毫秒出结果，识别精度对白底黑字 / 黑底白字的中英文都够用。

## 翻译引擎

自动降级，不需要任何 API Key：

1. 有道（主）
2. Google（能连通时才用，启动时自动探测）
3. MyMemory（兜底）

配置文件保存在 `%APPDATA%\FloatTrans\config.json`，出问题的日志在 `%APPDATA%\FloatTrans\app.log`。

## 打包成 exe（可选）

双击 `build_exe.bat`，生成单文件 `dist\FloatTrans.exe`，可以拷到任何 Windows 电脑直接运行，不需要装 Python。

> 打包依赖 PyInstaller、Pillow（生成图标用）和 winsdk（OCR 用），脚本会自动装。

## 小提示

- **全屏看电影**：请把播放器设成「无边框窗口 / 窗口化全屏」。独占全屏（exclusive fullscreen）时 Windows 会盖掉所有置顶窗口，任何悬浮窗都显示不出来。
- **想更不挡画面**：设置里把不透明度调到 70% 左右，或者收成小圆球。
- **Ctrl+Alt+T 没反应**：可能被别的软件占了，看设置里的「呼出热键」实际注册成了什么。
- **不想复制什么都翻译**：点底部 **自动** 切成 **手动**，或在设置里关掉。
- **OCR 认不准**：字太小、太糊、或者压在花哨画面上时会翻车。截图取词时框松一点，把整行文字都圈进去（框太紧会把字的上下边裁掉，认出来就会缺字）；细长的一条也能认，高度 20 像素以上基本没问题。
- **悬停取词太灵敏**：它只在**按住 Alt** 且鼠标**停住不动**时才触发，正常移动鼠标不会打扰你。
- 隐私：开启「复制即译」后，复制的文字会发给翻译服务商（有道/Google/MyMemory）；取词识别在本地完成，只有识别出来的文字会发出去。涉及密码、隐私内容时建议先关掉。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `float_trans.py` | 主程序（界面 + 翻译，纯标准库） |
| `screen_ocr.py` | 取词底层：GDI 截图 + Windows OCR + 文本清洗 |
| `启动翻译.bat` | 用 Python 直接启动（不弹黑框） |
| `build_exe.bat` | 一键打包 exe |
| `make_icon.py` | 生成 `app.ico` 图标 |
